# Campus Exchange - API Specification (v1)

Base URL: `/api/v1`

## Standard Request Headers
- `Content-Type: application/json`
- `Authorization: Bearer <JWT_TOKEN>` (for protected endpoints)
- `X-Request-Id: <UUID>` (optional, generated by server if omitted)

## Standard Error Format (PRISM-S Contract)
```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable explanation of the error",
    "requestId": "req_8f1a2b3c",
    "details": []
  }
}
```

---

## Endpoints

### 1. Authentication & Verification

#### `POST /api/v1/auth/verify`
Validates official college email boundary and returns JWT session token.
- **Access:** Public
- **Request Body:**
```json
{
  "officialEmail": "student@avih.edu.in",
  "verificationCode": "123456",
  "collegeId": "avih-gunthapalli"
}
```
- **Response (200 OK):**
```json
{
  "success": true,
  "requestId": "req_1a2b3c",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "isNewStudent": false,
  "student": {
    "studentId": "std_892341",
    "collegeId": "avih-gunthapalli",
    "collegeName": "Avanthi Institute of Engineering and Technology",
    "officialEmail": "student@avih.edu.in",
    "fullName": "Student User",
    "verificationStatus": "verified",
    "accountStatus": "active"
  }
}
```
- **Errors:** `400 VALIDATION_ERROR` (invalid email or unrecognized college domain), `429 RATE_LIMIT_EXCEEDED`.

#### `GET /api/v1/auth/me`
Retrieves current authenticated student profile.
- **Access:** Authenticated (Bearer JWT)
- **Response (200 OK):** Profile JSON

### 2. Marketplace Listings

#### `GET /api/v1/listings`
Browses active listings strictly for the authenticated student's college.
- **Access:** Verified Student
- **Query Parameters:**
  - `category` (string, optional): e.g., "Academic / Books"
  - `condition` (string, optional): e.g., "Good"
  - `search` (string, optional): Search keyword
  - `page` (integer, default: 1)
  - `limit` (integer, default: 20)
  - `sort` (string, default: "newest", options: "price_asc", "price_desc")
- **Response (200 OK):**
```json
{
  "success": true,
  "requestId": "req_123",
  "items": [
    {
      "listingId": "list_987654",
      "collegeId": "avih-gunthapalli",
      "sellerId": "std_12345",
      "sellerName": "Rahul Verma",
      "title": "Java Programming Book",
      "description": "Java programming book in good condition",
      "category": "Academic / Books",
      "price": 500,
      "condition": "Good",
      "photoRefs": ["java_book_1.jpg"],
      "status": "active",
      "createdAt": "2026-08-18T10:00:00.000Z"
    }
  ],
  "meta": {
    "total": 45,
    "page": 1,
    "limit": 20,
    "totalPages": 3,
    "hasMore": true
  }
}
```

#### `POST /api/v1/listings`
Creates an active listing. Derives `collegeId` and `sellerId` server-side from JWT.
- **Access:** Verified Student
- **Request Body:**
```json
{
  "title": "Java Programming Book",
  "description": "Java programming book in good condition",
  "category": "Academic / Books",
  "price": 500,
  "condition": "Good",
  "photoRefs": ["java_book_cover.jpg"]
}
```
- **Response (201 Created):**
```json
{
  "success": true,
  "listingId": "list_987654",
  "status": "active",
  "createdAt": "2026-08-18T10:00:00.000Z",
  "listing": { ... }
}
```

#### `GET /api/v1/listings/:listingId`
Retrieves single listing. Enforces college boundary.
- **Access:** Verified Student (same college)
- **Response (200 OK):** Listing object.
- **Errors:** `403 CROSS_COLLEGE_DENIED`, `404 LISTING_NOT_FOUND`.

#### `PATCH /api/v1/listings/:listingId`
Updates permitted listing fields.
- **Access:** Verified Seller (owner only)
- **Request Body:** `{ "title": "Updated Title", "price": 450 }`
- **Response (200 OK):** Updated listing.
- **Errors:** `403 SELLER_MISMATCH`, `409 INVALID_STATE_TRANSITION` (if already closed/sold).

#### `POST /api/v1/listings/:listingId/close`
Atomically closes or marks listing as sold. Idempotent against repeat requests.
- **Access:** Verified Seller (owner only)
- **Request Body:**
```json
{
  "finalStatus": "sold",
  "closedReason": "Completed sale with campus peer"
}
```
- **Response (200 OK):**
```json
{
  "success": true,
  "listingId": "list_987654",
  "status": "sold",
  "closedAt": "2026-08-18T10:30:00.000Z",
  "saleEventId": "evt_987123"
}
```
- **Errors:** `409 INVALID_STATE_TRANSITION` (if already sold or closed).

### 3. Chat & Messaging

#### `GET /api/v1/listings/:listingId/chat`
Retrieves conversation messages for a listing.
- **Access:** Verified Buyer or Seller (same college)

#### `POST /api/v1/listings/:listingId/chat`
Sends a listing-associated message.
- **Access:** Verified Buyer or Seller (same college)
- **Request Body:** `{ "message": "Hi, is this Java book available?" }`
- **Response (201 Created):** Created message and conversation context.

---

### 4. Moderation & Reports

#### `POST /api/v1/reports`
Submits a misleading listing or seller conduct report.
- **Access:** Verified Student
- **Request Body:**
```json
{
  "listingId": "list_987654",
  "reason": "Misleading Condition or Details",
  "description": "Book has missing pages not mentioned in listing."
}
```
- **Response (201 Created):** `{ "reportId": "rep_123", "status": "open" }`

---

### 5. Telemetry & Metrics

#### `GET /api/v1/metrics`
Calculates real-time pilot conversion rates against PRISM-R targets.
- **Access:** Authenticated Student / Project Team
- **Response (200 OK):** Metrics summary object.

#### `GET /api/v1/health`
Health check reporting uptime, database readiness, and SLA targets.
- **Access:** Public
- **Response (200 OK / 503 Service Unavailable):** Health report JSON.
